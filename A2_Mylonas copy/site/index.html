Geog 464 project

Forest Fires in Greece

This project maps wildfire incident records in Greece by municipality and highlights the reported burned area associated with each administrative boundary.

  • Incident source: Greek fire-service records with municipality names
  • Boundary source: GeoBoundaries administrative polygons for Greece
  • Current view: municipality-level, approximate but reviewable
  • Future goal: exact perimeter mapping with a cumulative-year slider

Project status

Period: 2014–2018

Coverage: Reviewed municipality matches

Method: Boundary crosswalk + area summary
