# Forest Fires in Greece

## Project description

This project maps reported wildfire burned area by municipality in Greece from 2014 through 2018. It is intended for geography students and readers interested in the distribution of reported wildfire impacts. Comparing municipalities provides geographic context for the incident records. Hover over or select a municipality on the map to view its reported burned-area total and incident count. The map uses representative points and municipal boundaries because the incident records do not include exact fire coordinates or fire-perimeter polygons.

## Data sources and licenses

- **Wildfire incident records:** [Greece data.gov.gr forest-fire dataset](https://new.data.gov.gr/dataset/363b7676-1604-438e-a5ee-545c29d15caf) ([CSV resource](https://new.data.gov.gr/dataset/363b7676-1604-438e-a5ee-545c29d15caf/resource/3676d1d4-14e4-4758-a5c1-ac6279afe7d3/download/export_mcp_forest_fires.csv)). The dataset page provides the applicable reuse terms; consult it before redistributing the records.
- **Municipality boundaries:** [geoBoundaries Greece ADM3 metadata](https://www.geoboundaries.org/api/current/gbOpen/GRC/ADM3/) ([GeoJSON download](https://github.com/wmgeolab/geoBoundaries/raw/9469f09/releaseData/gbOpen/GRC/ADM3/geoBoundaries-GRC-ADM3_simplified.geojson)). ## How to run it

Open `site/index.html` with Live Server in VS Code.

## Not in this iteration

- Exact fire-perimeter polygons were omitted because the incident dataset has no fire geometry or coordinates.
- A cumulative slider covering the 2000s to the present was omitted because the available incident records cover only 2014–2018, and this project does not have a complete historical perimeter dataset.
- Uncertain municipality matches were left off the map rather than assigned to possibly incorrect boundaries.
